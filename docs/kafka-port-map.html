포트 충돌 주의: Alertmanager 기본 포트(9093)는 KRaft 컨트롤러가 사용 중 — 호스트 네트워크로 같은 서버에 올리면 기동 실패. --web.listen-address=:9095로 변경해서 배치.

인증 없는 HTTP 4종(8081 · 8083 · 9090 · 9308)은 방화벽 제한이 유일한 보호막 — 특히 8081(스키마 등록·삭제 가능)과 8083(커넥터 조작 가능)은 반드시 대역 제한.
