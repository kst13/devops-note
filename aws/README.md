# AWS CLI

터미널에서 AWS를 조작·자동화하는 공식 명령줄 도구(AWS CLI)의 개념, 인증·설정, 운영 명령을 정리하는 디렉터리입니다.

콘솔에서 클릭하는 작업을 명령어·스크립트로 바꾸면 재현 가능하고 자동화하기 좋습니다. 이 문서는 단순 명령 나열보다, **어떤 기능이 있고 왜 그렇게 쓰는지**와 자주 쓰는 실전 예시를 함께 남기는 것을 목표로 합니다.

## 정리 원칙

- 개념은 짧게 정의하고, 직접 확인할 수 있는 명령어 예시를 함께 적습니다.
- 자주 쓰는 명령은 `commands/`에 모아 나중에 빠르게 찾아볼 수 있게 합니다.
- 자격증명·시크릿은 예시에 실제 값을 넣지 않고 자리표시자로 둡니다.
- 특정 명령 사용법만 적기보다, 인증·출력·자동화 관점에서 왜 그렇게 쓰는지도 남깁니다.

## 문서 구조

```text
concepts/          AWS CLI 핵심 개념과 인증·설정 정리
troubleshooting/   자주 만나는 문제와 해결 기록
commands/          서비스별 명령어와 운영 치트시트
examples/          직접 실행해볼 수 있는 예제
```
